# Crystal facet-to-slip pipeline report

A combined, visual report walking BFDH morphology → surface/attachment energy →
slip-plane screening → gamma-surface calculation for 30 molecular crystals.

Live at: https://zfahim57.github.io/BFDH-Slip-GAMMA/

## Contents

- `index.html` — the report itself: one section per material, with an
  interactive 3Dmol.js crystal-structure viewer, BFDH habit renders, and
  gamma-surface contour plots.
- `assets/` — BFDH habit images, gamma-surface contour images, and a locally
  vendored copy of [3Dmol.js](https://3dmol.org) so the page works offline.
- `pipeline_overview_summary.csv` — one row per candidate slip plane, with
  screening status and gamma-surface results.
- `report_metadata.json` — generation timestamp and summary counts.

Generated by `generate_pipeline_overview_report.py` from the
`crystal_facet_slip_workflow` pipeline (BFDH prediction, attachment/surface
energy ranking, slip-plane screening, and gamma-surface calculation).
